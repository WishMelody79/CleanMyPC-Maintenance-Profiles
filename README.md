## Usage

### For One-Click Maintenance:
1. Launch CleanMyPC and navigate to **Maintenance** → **Load Profile**.
2. Select the appropriate cleaning profile from the collection.
3. Review the system areas that will be scanned and cleaned.
4. Click **Run Scan** to identify files that can be safely removed.
5. Click **Clean** to remove selected items and free up disk space.

### For Privacy Cleaning:
1. Open CleanMyPC and go to **Privacy** → **Load Profile**.
2. Select the privacy protection profile for your browsers.
3. Choose which browser data to clear (cache, cookies, history, etc.).
4. Preview the items that will be removed.
5. Click **Clean** to remove sensitive data and protect your privacy.

### For Performance Optimization:
1. Navigate to **Performance** in CleanMyPC.
2. Load the optimization profile and review the recommended changes.
3. Configure startup items and disable unnecessary services.
4. Apply system tweaks for better responsiveness.
5. Restart your PC to finalize optimization settings.

### For Registry Cleanup:
1. Go to **Registry** → **Registry Cleaner**.
2. Load the registry profile and click **Scan**.
3. Review the registry issues found by the scan.
4. Select which issues to repair or ignore.
5. Create a registry backup before applying fixes (recommended).

### For Automation:
1. Open the `scripts` folder and review the automation scripts.
2. Edit the scripts to customize cleaning preferences and schedules.
3. Run the scripts manually via command line.
4. Configure Windows Task Scheduler for automatic weekly maintenance.
5. Review logs for results and any warnings.
